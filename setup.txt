Safety_Rental - Setup de entrega

Requisitos
----------
- PHP 8.2 o superior
- Composer
- MAMP con Apache y MySQL activos
- Git opcional

1. Descargar y abrir el proyecto
--------------------------------
Descomprimir el archivo ZIP en una carpeta local.
Abrir una terminal dentro de la carpeta del proyecto.

2. Instalar dependencias de PHP
-------------------------------
composer install

3. Configurar el entorno
------------------------
Asegurate de que exista el archivo .env. Si no existe, copialo desde .env.example:

Copy-Item .env.example .env

Luego verifica este contenido en .env:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=8889
DB_DATABASE=safety_rental
DB_USERNAME=root
DB_PASSWORD=root

4. Crear la base de datos en MAMP
---------------------------------
1. Abre MAMP.
2. Inicia Apache y MySQL.
3. Entra a phpMyAdmin.
4. Crea la base de datos llamada:
   safety_rental
5. Si ya existe, no la vuelvas a crear.

5. Ejecutar migraciones
-----------------------
php artisan migrate

Si aparece "Nothing to migrate", significa que ya estaban creadas.
Eso es correcto.

6. Generar la clave de Laravel
-----------------------------
php artisan key:generate

7. Iniciar la aplicacion
------------------------
php artisan serve

Abrir en el navegador:
http://127.0.0.1:8000/

8. Rutas principales
--------------------
- GET /reserves
- GET /reserves/create
- POST /reserves
- GET /reserves/{reserve}
- DELETE /reserves/{reserve}

9. Reiniciar el id de reserves
-----------------------------
Si queres volver a empezar desde 1 en la tabla reserves, ejecuta en phpMyAdmin:

ALTER TABLE reserves AUTO_INCREMENT = 1;

O si queres borrar todos los registros y reiniciar:

TRUNCATE TABLE reserves;

10. Verificacion final
----------------------
Puedes correr:

php artisan test

Esto valida que la aplicacion y las pruebas del taller siguen funcionando.

Observacion:
-------------
En este proyecto, la base de datos activa es MySQL con MAMP. El uso de SQLite queda como valor por defecto del framework, pero no es la configuracion real del proyecto.
