Taller 01 - Reserve

Requisitos
-----------
- PHP 8.3 o superior
- Composer
- Node.js y npm (opcionales para esta interfaz, pero recomendados para Laravel)
- SQLite para la configuracion por defecto, o MySQL si se prefiere

Instalacion desde cero
----------------------
1. Abrir una terminal en la carpeta del proyecto.
2. Instalar las dependencias de PHP:

   composer install

3. Crear el archivo de entorno:

   copy .env.example .env

   En PowerShell tambien puede usarse:

   Copy-Item .env.example .env

4. Generar la clave de la aplicacion:

   php artisan key:generate

Base de datos con SQLite (opcion recomendada para probar)
----------------------------------------------------------
El archivo .env.example ya usa SQLite. Crear el archivo de base de datos si no existe:

   New-Item database\database.sqlite -ItemType File

Si el archivo ya existe, no es necesario repetir ese comando. Ejecutar las migrations:

   php artisan migrate

Base de datos con MySQL (opcional)
-----------------------------------
Crear una base de datos vacia en MySQL y modificar solamente estas variables en .env:

   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=nombre_de_la_base
   DB_USERNAME=usuario_de_mysql
   DB_PASSWORD=contrasena_de_mysql

Luego ejecutar:

   php artisan migrate

No se requieren foreign keys ni tablas de User, Car, Location, Payment o State para este taller.

Iniciar la aplicacion
---------------------
Ejecutar:

   php artisan serve

Abrir en el navegador:

   http://127.0.0.1:8000/

Rutas principales
-----------------
- GET    /                         Pagina inicial
- GET    /reserves                 Listado de Reserves
- GET    /reserves/create          Formulario de creacion
- POST   /reserves                 Guardar una Reserve
- GET    /reserves/{reserve}       Detalle de una Reserve
- DELETE /reserves/{reserve}       Eliminar una Reserve

Comprobaciones utiles
---------------------
Ver las rutas:

   php artisan route:list

Ejecutar las pruebas:

   php artisan test

Limpiar caches si se cambia configuracion o rutas:

   php artisan optimize:clear

La aplicacion solo implementa los atributos primitivos id, code, state, startDate, endDate y createAt, ademas de created_at y updated_at de Laravel.
